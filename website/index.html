gramm

Grammar of graphics plotting for MATLAB

GitHub File Exchange Paper (JOSS)

Gramm is a MATLAB toolbox that enables the rapid creation of complex, publication-quality figures. Its design philosophy focuses on a declarative approach, where users specify the desired end result, as opposed to the traditional imperative method involving for loops, if/else statements, etc. Install it from MATLAB's Add-ons explorer by searching for "gramm".
