Build the examples

If the examples have not been generated, run these commands in MATLAB from the repository root:

openProject('gramm.prj');
buildtool runVega
buildtool publish

runVega tests the Vega examples and creates the interactive comparison gallery. publish creates the example index linked above. Then reload this page.

For browser viewing, serve the repository root over HTTP:

python3 -m http.server 8000 --bind 127.0.0.1

Then open this page on localhost.
