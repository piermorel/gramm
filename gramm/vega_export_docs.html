Gramm Vega Export Documentation

Documentation for the Vega-export function in this Gramm branch, including usage and side-by-side examples.

Overview

This variation extends Gramm with export_vega, which translates a drawn Gramm object into a Vega specification and writes export files for browser rendering.

The generated outputs complement the standard Gramm SVG export: SVG gives a static snapshot, while Vega gives a declarative spec that can be rendered and interacted with in web contexts.

What Is Vega

Vega is a JSON-based visualization grammar. A Vega spec defines data, scales, axes, and marks, and the Vega runtime renders that spec in the browser. Learn more at vega.github.io/vega.

As the chart is specified as JSON, it is portable and can be embedded in documentation, apps, and dashboards without requiring MATLAB at render time.

Use Cases

  • Ship interactive versions of Gramm figures to web pages while preserving the MATLAB preprocessing pipeline.
  • Compare SVG parity against Vega output during renderer development and regression checks.
  • Share plot specs (.json) as reproducible artifacts that downstream web tools can load directly.

General Tutorial: Calling export_vega

Typical flow: build a Gramm object, draw it, then call export_vega with file and rendering options.

Minimal Example
x = randn(300, 1);
y = 0.35 * x + randn(300, 1);
group = repelem(["A", "B", "C"], 100)';

g = gramm('x', x, 'y', y, 'color', group);
g.geom_point();
g.stat_glm();
g.set_names('x', 'Signal', 'y', 'Response');
g.draw();

export_vega(g, ...
    'file_name', 'tutorial_scatter_glm', ...
    'export_path', './test/gramm_vega', ...
    'width', '500', ...
    'height', '340', ...
    'x', 'Signal', ...
    'y', 'Response', ...
    'interactive', 'true', ...
    'tooltip', 'true', ...
    'title', 'Scatter + GLM');

Argument reference (example value and meaning):

  • g = g: the drawn Gramm object to export.
  • 'file_name', 'tutorial_scatter_glm': base name of output files; writes tutorial_scatter_glm.json and tutorial_scatter_glm.html.
  • 'export_path', './test/gramm_vega': directory where export files are saved.
  • 'x', 'Signal': x-axis title in the Vega chart.
  • 'y', 'Response': y-axis title in the Vega chart.
  • 'title', 'Scatter + GLM': chart title shown in rendered output.
  • 'width', '500': plot width in pixels.
  • 'height', '340': plot height in pixels.
  • 'interactive', 'true': enables interactive legend behavior when color groups are present.
  • 'tooltip', 'true': enables hover tooltips on marks.

The function writes both <file_name>.json and <file_name>.html into export_path.
